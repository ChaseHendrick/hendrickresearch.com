Connect your MPC

01

Plug in

Use a USB-C data cable to the XL’s computer port. Keep it in standalone mode. Open this page in current Chrome or Edge on Windows or Mac.

02

Load a sound

In MPC MIDI/Sync preferences, enable Track on USB MIDI Port 1. Load a polyphonic ambient instrument, set its input to channel 1 and monitoring to In or Merge.

03

Let it evolve

A single recognizable MPC port is selected automatically after permission. Play your arrangement. Turn simple setup off to use bass channel 2, pads 3 and melody 4.

A selected MIDI port confirms browser access, not audible hardware playback. Clock is off by default. When enabled, configure the MPC to receive MIDI Clock; Akai notes that external MIDI Clock disables audio recording. Keep it off when recording your guitar.

Learn the CC slider on the MPC after enabling Control on its input port. This browser companion does not request system-exclusive permission or send MMC commands. MIDI Clock Start/Stop is available only when you enable clock.

Optional local or cloud modelAI arrangement + local MIDI rendering

The model designs a JSON musical plan. This studio renders the notes on the CPU. Ollama or LM Studio manages its own GPU inference; no model runs inside this page. Install and load a model in your server first.

Only Generate or Evolve with the model composer selected sends your musical direction to this endpoint. Cloud connections need HTTPS and browser CORS support. Local servers may require Local Network Access permission and an allowed origin. For Ollama, allow this page’s exact origin in OLLAMA_ORIGINS, then restart the server. Do not expose your server publicly. Keys are never saved or included in MIDI files.
