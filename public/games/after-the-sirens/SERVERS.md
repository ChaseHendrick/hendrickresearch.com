# Public After the Sirens worlds

Add an operator-approved reachable public world to servers.json with version 1. Each record uses name, url (wss:// from this HTTPS site), public:true, capacity:20, players (0 to 20) and difficulty (calm, standard or hard). Never include private access keys or player identities. Static counts are operator-maintained; a running directory reports live counts.

The catalogue starts empty until real public hosts are submitted. The game can also browse a compatible directory. Hosting instructions: https://github.com/ChaseHendrick/After-the-Sirens/blob/main/docs/MULTIPLAYER.md.
